<a id="leak-detection"></a>

## 🚨 配置泄露检测与智能发现

<details>
<summary><strong>点击展开</strong></summary>

客户有时会把自己的配置或订阅链接发到公开频道。泄露扫描器会找到这些帖子，并关联到对应的服务。

- 🔐 **指纹索引**：对 3X-UI、PasarGuard 和 Hiddify 上每个有效服务的机密值（UUID、协议密码、订阅令牌）做 SHA-256 哈希并写入索引；原始值从不保存。索引每隔几分钟重建一次，购买或切断访问后会立即刷新对应的单个服务
- 🔎 **运行在用户机器人会话上的扫描器**：解析公开 Telegram 帖子中的 `vless` / `vmess` / `trojan` / `ss` 链接和订阅链接，哈希后与索引比对；已列入的频道会扫描新帖，同时执行全局关键词搜索
- 🚨 **管理员告警**：命中时管理员会收到告警（设置了报告群时发到“🚨 配置泄露”话题），带有 *轮换链接 / 警告 / 忽略* 按钮；警告可选择是否自动撤销访问
- 🛡️ **账号保护**：每分钟请求上限并带随机间隔，遇到 Telegram FloodWait 完全停止，并且客户优先：每次收到客户消息后，扫描器会安静几秒

**智能发现**（🚨 泄露检测 → 🧭 智能发现）让扫描器不再只监控手动添加的频道，而是自己寻找来源：

- **Telegram 搜索**：内置波斯语 / 英语 / 俄语 / 中文关键词。关键词会学习：效果好的更常运行，并从优质频道的标题中衍生新关键词。管理员可以添加自己的关键词，并在机器人菜单中启用、停用或删除任意关键词。
- **链接爬取**：帖子、频道简介和搜索结果中的 `t.me/...`、`@username` 和邀请链接会成为候选。
- **加入前评分**：*不加入* 就读取最近约 40 条帖子（并立即扫描泄露）。评分 = 配置密度、新鲜度、发帖频率、标题相关度、成员数。
- **谨慎加入**：每日上限、总上限、随机延迟、遇到 FloodWait 完全停止。模式：自动、管理员审批，或仅监控（公开频道，不加入）。
- **实时监控**已加入的频道（新帖 *和* 编辑过的帖子），包括隐藏在文字超链接和按钮后的链接。
- **自动退出**：扫描器自己加入、14 天内没有产生任何配置或泄露的频道。你原本就在的频道永远不会退出。

所有功能默认关闭（`leak_scanner_enabled`、`leak_discovery_enabled`）。由于扫描器与用户机器人共用账号，请保持较低的加入上限，或为扫描器单独使用一个 Telegram 账号：`manage.sh` 选项 40（Telegram 账号）或 `python userbot.py login-scanner`（撤销：`logout-scanner`，状态：`status-scanner`）。它无需重启即可启动，也不会影响面向客户的账号。

测试：`python -m unittest test_leak_scanner test_leak_discovery`

</details>

## 📣 AI 频道帖子

<details>
<summary><strong>点击展开</strong></summary>

销售频道的文案与横幅通过 [Jarvis](https://jarvis.you) 网关生成（默认 API 地址为 `https://api.jarvis.you/v1`）。这一部分与客服助手和管理员助手完全独立。

**设置（在机器人内）：** 营销与增长 → 频道帖子 / 深链接与频道帖子工具 → AI 帖子 → ⚙️ AI 设置与学习

1. 创建 Jarvis 账号和 API 密钥（密钥以 `pmai_` 开头），点击“🔑 Jarvis 密钥”并发送（多个密钥：每行一个，出错时自动轮换）。
2. 点击“🧪 测试文本”。如有需要可更换文本或图像模型（默认：`CLAUDE_6_5_HAIKU` 与 `gemini-3-1-flash-image`）。
3. 为提高横幅质量，请发送透明背景的 PNG 徽标，并可选择提供一张示例横幅作为风格参考。
4. 机器人内的完整指南位于“📖 Jarvis 指南”。

**功能**

- ✍️ 围绕管理员主题生成一段完整文案（最多 1500 字符），只使用真实的商品、价格、折扣和优惠码（以及管理员自己写的内容）；支持重写和更换主题；手动文案模式无需任何 AI 密钥
- 🏷️ 价格准确：AI 会拿到原价与折后价、真实折扣百分比、真实截止日期（绝不使用小时倒计时）以及剩余购买/使用次数，并把测试配置方案、幸运转盘奖品和其他优惠作为事实依据
- 🖼️ 每种帖子类型（折扣、优惠码、商品、测试、转盘）都有对应的设计模板，并带有来自数据库的真实紧迫感标签（7 天内截止，或剩余购买/使用次数很少）
- 🎯 徽标模式：“精确”（默认）原样放置徽标，不让 AI 干预；“AI 参考”将徽标作为参考图传给模型，不被接受时自动回退到精确模式
- 🖼 风格参考横幅、可编辑的基础提示词，以及品牌模板（颜色、徽标、波斯语字体、默认尺寸、预览）
- 🗳 AI 生成的投票与问答
- 📅 每周计划：AI 提出多条角度不同的帖子，管理员一次性批准
- 🗂 帖子管理：草稿、定时帖子（自动发送）、发送、编辑、置顶/取消置顶、删除和统计
- 💡 添加新商品、库存偏低或创建公开优惠码时，自动建议管理员创建帖子
- 🔗 深链接按钮（优惠码、测试配置、幸运转盘或自定义活动参数），以及独立工具 `channel_post_tool.py` 和 `channel_add_button_tool.py`

</details>

<a id="business"></a>

## 💼 Telegram Business

<details>
<summary><strong>点击展开</strong></summary>

卖家可以把主机器人连接到自己的 Telegram Business 账号（设置 → Telegram Business → 聊天机器人），之后机器人会在卖家的私聊中代表卖家回复客户。该功能仅限主机器人（不含代理机器人），在管理员开启之前**默认关闭**。

- 🔗 **连接管理** — 按连接保存 `business_connection` 和 `business_message` 更新（所有者、回复/读取权限、启用/停用）；连接启用或断开时会通知管理员
- 🤖 **AI 自动回复** — 通过 AI 客服助手基于真实数据回复客户消息；此处仅提供只读工具：价格与商品、支付方式、服务状态、服务器国家、服务历史和免费测试配置
- 🔒 **商务聊天中不执行任何财务操作** — 钱包购买、续费和服务变更均被禁用；此类请求会转交卖家
- 🛡 **安全过滤** — 机器人会忽略卖家本人、管理员、其他机器人和已封禁用户的消息；防垃圾和全局机器人开关同样适用于此通道；非文本消息会被忽略
- 🤝 **转人工** — 助手升级后会在该聊天中保持静默，卖家会在主机器人收到包含最近消息的通知，以及“打开聊天”和“恢复自动模式”按钮
- ✏️ **编辑/删除追踪** — 已转人工聊天中客户的编辑和删除会通知卖家（可关闭）；消息日志几天后自动清理
- ✅ **标记已读** — 可选；需要账号所有者授予 `can_read_messages` 权限
- 🛒 **购买卡片（可选，默认关闭）** — 客户想购买时，机器人发送商品卡片（名称、价格、流量、时长、说明），并附带一个链接按钮，打开机器人并定位到该商品。支付和交付始终在机器人内完成，商务聊天中不进行任何支付
- ⚙️ **管理面板** — **管理员与权限 → 💼 Telegram Business**：总开关、标记已读、编辑/删除通知、购买卡片开关、活跃连接列表、每个连接的自动回复开关、首条消息（每个新聊天开始时发送一次）、客户 ID 例外列表以及已转人工的聊天列表

> 商务聊天中有意不使用内联 callback 按钮，而是使用 URL 按钮，因为商务聊天中的 callback 投递尚未得到验证。

</details>

## 🏢 代理等级与代理申请

<details>
<summary><strong>点击展开</strong></summary>

代理权限分为四个可由管理员编辑的等级（Telegram 管理端 → 代理、Web 管理后台和小程序管理端）。每个等级有自己的名称、图标、简介和说明，可以开关，可设置带有效期的会员费（到期和提醒自动处理），并可设为自动通过申请。

| 等级 | 模式 | 代理获得的内容 |
|---|---|---|
| 🥉 青铜 | 佣金 | 主机器人内的专属链接；通过该链接进入的客户每次购买，按比例把佣金记入代理钱包。无需本金 |
| 🥈 白银 | 折扣 | 没有链接也没有机器人：在主机器人内享受永久折扣购买，一次买得越多折扣越大（每个等级的数量折扣） |
| 🥇 黄金 | 固定商品 | 自己的 Web 面板、小程序和独立机器人；预付批量购买现成商品（按数量计）并转售 |
| 👑 VIP | 流量额度 | 自己的 Web 面板、小程序和独立机器人；购买一个流量池，可按任意价格创建任意商品；服务直接在分配给该代理的面板上创建（VIP 没有配置库存） |

- 📝 **在机器人内申请代理**：用户点按钮申请等级。青铜由用户提出佣金比例（1–100），管理员接受或给出自己的比例；白银由用户申请等级，管理员设定批准的永久折扣（1–100）；设为自动通过的等级会立即生效
- 🧭 **黄金/VIP 申请表**：机器人类型（独立机器人 / 专属链接 / 无机器人）、Web 面板、小程序和供货模式（流量或现成商品）；所有者可以把其中任意一项从表单中完全移除。管理员可在机器人、Web 面板和小程序中查看申请、凭证和状态，会员费通过钱包或支付网关支付
- 🪜 **等级限制与升级**：最低数量和流量、佣金范围、永久折扣以及每个等级的数量折扣；用户可以申请升级
- 💳 **后付费额度**：每个等级有默认额度，管理员还可在代理卡片中为单个代理设置专属额度。钱包余额可以透支到负的额度上限；钱包页面显示余额、额度、欠款和可用额度；达到上限时购买、续费和自动续费会停止并提示“请先充值”；钱包转账只使用真实余额。每一笔变动都会写入钱包流水
- 🌐 **没有自己机器人的代理**可以在自己的 Web 面板创建服务（`/api/reseller/self-service`），机器人也可以为其签发 Web 面板登录链接
- 🔗 旧模式仍与等级并存：拥有自己目录和卡号的关联代理，以及数据库相互隔离的独立代理机器人

</details>

<a id="ssh-nodes"></a>

## 🔐 SSH、OpenVPN 与 WireGuard 节点

<details>
<summary><strong>点击展开</strong></summary>

除了 VPN 面板，ShopVPN 还能在普通 Linux 服务器上通过 **SSH、OpenVPN 和 WireGuard** 销售账号。这些“节点”的行为类似面板节点：只用于创建账号，用户通过常规的购买、订阅和交付流程获得。

- 🧩 **节点 Agent**：每个节点运行一个带认证的小型 Agent（`ssh_node_agent.py`，TLS 并固定证书指纹），机器人通过有文档的 HTTP API 与其通信，而不是执行原始 root 命令。机密通过环境变量引用（`env:NAME`），从不以明文存入 SQLite
- ⚡ **一步安装**：在管理后台只需提供 IP 和 root 密码：面板通过 SSH 连接，上传并安装 Agent，生成令牌和证书，把 Agent 的访问限制为面板服务器的 IP，登记节点，并执行真实测试（创建并删除试用账号），同时实时显示安装进度。root 密码只在内存中使用，不会保存或写入日志。之后可以给已有节点追加协议，也可手动运行 `deploy/install-shopvpn-ssh-agent.sh [ssh|openvpn|wireguard]` 安装
- 🔌 **SSH 账号**：每个账号有独立隔离的 `sshd` 监听器和唯一端口（端口范围可按节点配置），流量用 nftables 端口计数器按账号统计
- 🛡️ **OpenVPN 与 WireGuard**：两者都有按账号的流量统计，`deploy/` 中还提供 NAT 服务和 OpenVPN 断开脚本
- 🌐 **主机（Host）**：类似 PasarGuard 的 Host：每个节点可为每种协议设置一个或多个主机（节点域名/IP 或隧道/中继地址，端口可选）。只有面向用户的输出在展示时生成，因此修改主机会同时作用于已有账号
- 📤 **交付格式**：`ssh://BASE64(user:pass)@host:port#remark` 链接、`.ovpn` 文件和 WireGuard `.conf` 文件；SSH 密码加密存储（Fernet，密钥来自 `SHOPVPN_SSH_CREDENTIAL_KEY`），用于用户自助获取
- 🔗 **共享流量池**：组合服务把 VPN 配置和 SSH 账号放进同一个流量池，共用一个流量额度和一个到期时间。`quota_reconciler.py` 通过现有面板 provider 读取 VPN 计数，通过 Agent 读取节点计数（只有节点报告统计就绪时才接受节点计数，缺失的计数绝不当作零），然后执行共享上限。SSH 用量通过降低用户在 VPN 面板上的流量上限来体现（上限 = 面板已用 + 池中剩余），因此共享流量一用完，面板自己就会切断用户；续费时新的到期时间会写入各节点
- 🧰 **管理**：节点、账号和流量池可在 Telegram 管理机器人、Web 管理后台和小程序管理端管理；命令行工具 `ssh_admin.py` 覆盖终端操作。节点不可达时，“强制删除”只会把它从面板中移除
- ✅ 测试：`python -m unittest test_ssh_hosts test_ssh_uri test_ssh_order_row test_ssh_unreachable_node test_quota_panel_sync`

</details>

- 🔁 通过文件 SHA-256 哈希与回单流水号检测完全重复，并用感知哈希 (dHash) 发现重新压缩或裁剪后的复用（仅警告）
- 🤖 多模型视觉分析：Gemini，并行运行所有其他已配置的智能体（Groq、OpenRouter、Mistral、Cohere、Cloudflare Workers AI、OpenAI、Claude 以及自定义服务商）
- 🏦 更多提示性检查：根据来源卡号前缀推断的银行与回单上可见的银行品牌是否一致，以及发送的文件名（截图时间与发送时间相差过大，或含图片编辑工具关键词；仅当回单作为 Telegram 文件发送时）
- 🏛️ 银行查询（可选，默认关闭）：始终将 IBAN 中的银行代码与卡片所属银行比对，也可接入任意官方的卡号/IBAN 查询 HTTP API（URL、请求头、请求体和响应路径在设置中配置）来核验卡号 ↔ IBAN 及持卡人姓名；结果会被缓存，服务不可用绝不视为通过，只有在你启用后，收款方明确不符才会自动拒绝
- 🔢 确定性 OCR 校验：卡号 (Luhn + 伊朗银行前缀)、IBAN 校验和、以土曼或里亚尔核对金额、流水号重复使用
- 🕵️ 取证分析：JPEG 误差级别分析 (ELA)、图片元数据扫描、截图状态栏时间与发送时间比对、银行/户名与文字金额一致性
- ⚖️ 仅在完全重复（开启自动拒绝时）或至少两个独立信号一致时才自动拒绝
- 🎛️ 管理员可开关检测、自动拒绝、严格模式与多模型；学习报告根据管理员的通过/拒绝决定调整各模型权重

### 🌐 自动翻译引擎与 16 种语言

- 🗺️ 内置语言目录：波斯语、英语、土耳其语、阿拉伯语、俄语、德语、法语、西班牙语、意大利语、葡萄牙语、中文、日语、韩语、荷兰语、波兰语和乌克兰语

## 🔗 专用订阅服务器

订阅链接由你自己的域名提供（绝不暴露面板地址）。在浏览器中打开链接会显示一个网页（黑白设计，支持浅色/深色模式），包含用量、到期时间、用量图表、配置、二维码、“添加到应用”按钮，以及 iOS / Android / Windows / macOS / Linux 的应用列表；VPN 应用则把同一链接当作普通订阅使用。

- **首次设置（仅限 `manage.sh`）**：选项 29（域名、nginx、SSL、端口 8004 上的 `v2raybot-sub` 服务，并保存 `DEDICATED_SUB_URL`），30 开/关，31 更新，32 删除（`D` 显示状态）。请先把域名的 A 记录指向服务器。
- **其余都在 Telegram 机器人中配置**：管理面板 → 商品与配置 → 专用订阅：开/关（无需重启）、页面外观（板块、品牌、Logo、公告、客服、页脚、主题）、订阅输出（配置文件标题、更新间隔、显示剩余流量/天数的“第一行”、已过期或已耗尽服务的占位配置）、应用（隐藏/显示、推荐、自定义应用）、FAQ、统计和访问日志。
- 关闭后，已发出的链接仍可使用（直接透传），而新链接重新使用面板地址。
- `/sub/smart/<token>`（`/smartsub`）同样由此服务器提供，可把多个订阅合并为一个链接。
- 代码：`dedicated_sub.py`（核心）、`sub_server/`（服务器 + 网页）、`admin_dedicated_sub.py`（机器人菜单）、`db/dedicated_sub.py`；测试：`python -m unittest test_dedicated_sub`。
- 输出格式（Clash / sing-box / v2ray）由面板根据应用的 User-Agent 选择，订阅服务器会转发该 User-Agent。“第一行”和占位配置仅适用于链接列表型订阅（vless/vmess/...）。
