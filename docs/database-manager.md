# مدیریت دیتابیس در پنل وب ShopVPN

## دسترسی
بخش «مدیریت دیتابیس» فقط در پنل بات اصلی و فقط برای حسابی با نقش `owner` نمایش داده می‌شود. مالک یا ادمین پنل نمایندگی، حتی اگر نقش او `owner` باشد، به APIهای این بخش دسترسی ندارد. کنترل دسترسی در سمت سرور انجام می‌شود و مخفی‌کردن منو صرفاً جنبه رابط کاربری دارد.

## امکانات
- فهرست جداول و تعداد ردیف‌ها
- نمایش داده‌ها با صفحه‌بندی، جستجو و مرتب‌سازی
- نمایش ساختار ستون‌ها و ایندکس‌ها
- دانلود بکاپ سازگار با WAL با `sqlite3.Connection.backup()`
- کنسول SQL محدود به یک دستور `SELECT`، سقف ۵۰۰ ردیف و زمان اجرای ۲ ثانیه
- ماسک‌کردن نام ستون‌های حاوی token، secret، password، hash، config، credential و کلیدها
- ویرایش و حذف ردیف‌های دارای کلید اصلی، با بکاپ پیش از هر تغییر
- ثبت لاگ تغییرات در جدول داخلی `_shopvpn_db_audit`
- خروجی CSV/JSON، ورود JSON تا ۵۰۰۰ ردیف و اجرای VACUUM با بکاپ قبلی

## نکات عملیاتی و امنیتی
- اتصال نمایش و کنسول SQL با URI دارای `mode=ro` باز می‌شود.
- نام جدول فقط از `sqlite_master` خوانده و با فهرست مجاز تطبیق داده می‌شود.
- کنسول SQL از authorizer داخلی SQLite استفاده می‌کند؛ عملیات نوشتن، `ATTACH`، `PRAGMA` و بارگذاری extension مجاز نیستند. خواندن مستقیم ستون‌های حساس در کنسول نیز مسدود است.
- عملیات ویرایش/حذف/ورود JSON فقط با دسترسی owner در تنانت اصلی انجام می‌شود و پیش از تغییر، بکاپ گرفته می‌شود.
- فایل‌های بکاپ در پوشه `backups/` کنار دیتابیس ذخیره می‌شوند. برای مدیریت فضای دیسک، سیاست نگهداری و حذف بکاپ‌های قدیمی را جداگانه تنظیم کنید.
- قبل از استفاده عملیاتی، روی نسخه آزمایشی دیتابیس و با بکاپ قابل‌بازیابی تست انجام دهید.

## محدودیت‌های فعلی
- ورود داده در حال حاضر از JSON پشتیبانی می‌کند؛ ورود CSV در رابط کاربری ارائه نشده است.
- ویرایش ردیف به وجود کلید اصلی نیاز دارد.
- فیلدهای حساس از رابط ویرایش و ورود مسدود شده‌اند؛ برای تغییر آن‌ها باید از مسیرهای مدیریتی اختصاصی برنامه استفاده شود.
