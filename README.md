## 📖 معرفی

**Shopvpn** یک بات تلگرام حرفه‌ای برای فروش کانفیگ‌های V2Ray است که به‌صورت کامل با Python و aiogram 3 نوشته شده و شامل یک **Mini App** اختصاصی (با بک‌اند FastAPI) برای تجربه‌ی خرید مدرن داخل تلگرام است. این پروژه برای استفاده‌ی واقعی و تجاری طراحی شده: پرداخت کارت‌به‌کارت با تایید ادمین یا به‌صورت کاملاً خودکار از طریق آبان گیت وی، سیستم نمایندگی چندسطحی (ریسلر با بات مستقل)، کیف پول، کد تخفیف، چرخ‌شانس، یادآوری خودکار تمدید/اتمام حجم، سیستم تیکت پشتیبانی، بکاپ‌گیری خودکار و بازیابی، لاگ کامل فعالیت ادمین‌ها و بسیاری امکانات دیگر — همه با یک تجربه‌ی کاربری کاملاً فارسی و راست‌چین.

## ✨ امکانات

### 🤖 بات اصلی
- 🔑 بانک کانفیگ اختصاصی و یکتا برای هر کاربر، به‌همراه **تحویل خودکار (Auto-Provision)** از طریق اتصال مستقیم به پنل‌های **PasarGuard**، **Marzban**، **Marzneshin**، **Hiddify** و **3X-UI** (ساخت کاربر و اعتبار حجمی به‌صورت آنی روی خود پنل، بدون نیاز به انبار کانفیگ دستی — به‌ویژه برای بات‌های نمایندگی)
- 🔗 **اتصال مستقیم محصولات عادی به یک پنل مشخص (بدون نمایندگی)** — ادمین موقع ساخت محصول می‌تواند آن را به یک پنل VPN وصل کند؛ با هر خرید (چه از بانک کانفیگ دستی و چه بدون آن)، یک کاربر واقعی همان لحظه روی همان پنل ساخته و تحویل داده می‌شود
- 🔢 **خرید چندتایی** — انتخاب تعداد با دکمه‌ی +/- در لحظه‌ی خرید، محاسبه‌ی خودکار جمع کل و تحویل هم‌زمان چند کانفیگ از انبار
- 💳 پرداخت کارت‌به‌کارت با تایید دستی ادمین (همراه با عکس رسید)
- 🏧 **درگاه پرداخت کارت‌به‌کارت خودکار (آبان گیت وی)** — به‌عنوان جایگزین تایید دستی؛ ساخت فاکتور خودکار برای خرید محصول، کانفیگ سفارشی و شارژ کیف پول، استعلام مستقیم وضعیت از API (بدون اعتماد به بدنه‌ی وب‌هوک) و تحویل آنی بدون نیاز به دخالت ادمین؛ هر بات (اصلی/نمایندگی) می‌تواند از داخل پنل مدیریت خودش (دکمه‌ی «تنظیم درگاه آبان گیت وی») یک API Key اختصاصی ثبت کند؛ ادمین یک بخش جدا برای مشاهده، بررسی دستی وضعیت و لغو فاکتورهای آبان گیت وی در اختیار دارد
- 💎 **درگاه پرداخت کریپتو (Plisio)** — ساخت فاکتور خودکار، تایید پرداخت از طریق کال‌بک امن (اعتبارسنجی امضا)، تحویل آنی کانفیگ بدون نیاز به تایید دستی؛ هر بات (اصلی/نمایندگی) می‌تواند کلید API اختصاصی خودش را تنظیم کند
- 🧩 **موتور درگاه پرداخت سفارشی/پویا (Generic Payment Gateway)** — ادمین بدون نوشتن حتی یک خط کد، هر درگاه پرداختی که یک HTTP API دارد را از داخل پنل تعریف می‌کند: آدرس API ساخت فاکتور، هدرها و بدنه‌ی درخواست با پلیس‌هولدر (`{amount}`, `{callback_url}`, `{api_key}` و...)، و این‌که از پاسخ JSON کدام فیلدها خوانده شود (مسیر ساده شبیه JSONPath، بدون کتابخانه‌ی جانبی)؛ پشتیبانی از استعلام دستی وضعیت (verify) و وب‌هوک با چند حالت احراز هویت (`header_secret`, `query_secret`, `hmac_sha256`)؛ کاملاً مستقل از آبان گیت‌وی و Plisio، یعنی می‌توان هم‌زمان چند درگاه دلخواه دیگر (زرین‌پال، نکست‌پی و...) را بدون کد جدید اضافه کرد
- 💱 **نرخ خودکار دلار/تتر به تومان** — دریافت زنده از چند منبع پشتیبان (با کش کوتاه‌مدت و نرخ دستی پشتیبان در صورت قطعی همه‌ی منابع) برای قیمت‌گذاری لحظه‌ای محصولات کریپتویی
- 💰 سیستم کیف پول داخلی با درخواست شارژ، ارسال رسید و تایید ادمین
- 🗂️ مدیریت کامل دسته‌بندی و محصولات (فعال/غیرفعال، قیمت، موجودی)
- 🧪 کانفیگ تست رایگان با محدودیت قابل‌تنظیم برای هر کاربر
- 🚫 مسدودسازی کاربر توسط ادمین (بدون تاثیر روی دسترسی خود ادمین‌ها)
- 📡 عضویت اجباری در کانال قبل از استفاده از بات (با حالت fail-open برای جلوگیری از قفل‌شدن کامل بات در صورت تنظیم اشتباه)
- 📊 اطلاعات زنده‌ی اشتراک (حجم مصرفی/باقی‌مانده و تاریخ انقضا) مستقیماً از روی لینک ساب کاربر، مستقل از نوع پنل (Marzban / X-UI / Marzneshin / Hiddify و...)
- ⏰ دو سیستم یادآوری خودکار و مستقل از هم: **یادآوری نزدیک‌شدن انقضا** و **یادآوری اتمام حجم** (بر مبنای درصد یا گیگابایت باقی‌مانده)، هرکدام همراه با کد تخفیف اختصاصی و محدود به زمان
- ⚠️ هشدار خودکار اتمام موجودی محصول به همه‌ی ادمین‌ها با آستانه‌ی قابل‌تنظیم
- 📱 تحویل کانفیگ به‌صورت متن + QR Code
- 🎫 **سیستم تیکت پشتیبانی** داخل بات (ایجاد تیکت، ادمین می‌تواند تیکت را claim کند، پاسخ بدهد و ببندد) به‌همراه یک کانال جدا برای پیام مستقیم/چت زنده با پشتیبانی
- 🎨 دکمه‌های رنگی شیشه‌ای طبق Bot API 9.4 (خاکستری/آبی/سبز/قرمز) برای تمام دکمه‌های منوی اصلی و پنل مدیریت
- 🧩 **چیدمان و شخصی‌سازی کامل منوی اصلی** — تغییر ترتیب، نمایش/عدم‌نمایش، متن و رنگ هر دکمه از داخل پنل مدیریت
- 🏷️ برندسازی فروشگاه (نام فروشگاه، متن بنر Mini App) از داخل پنل مدیریت
- 🏢 پشتیبانی از بات‌های نمایندگی مستقل (Reseller Bots) با دیتابیس جدا برای هر نماینده و اجرای هم‌زمان چند بات با یک Dispatcher مشترک
- 💾 **ذخیره‌ی پایدار وضعیت مکالمات (FSM Storage روی SQLite)** — برخلاف حافظه‌ی موقت پیش‌فرض aiogram، وضعیت مکالمات نیمه‌کاره (مثل «در انتظار عکس رسید») روی دیسک ذخیره می‌شود و با ری‌استارت/آپدیت/کرش بات از بین نمی‌رود؛ برای هر بات (اصلی/نمایندگی) به‌صورت مستقل
- ⏳ **پیام‌های خودحذف‌شونده (Temp Messages)** — ادمین می‌تواند به هر کاربر پیامی بفرستد که بعد از مدت مشخص (دقیقه/ساعت/روز، قابل‌تنظیم) خودکار حذف شود؛ همین مکانیزم برای حذف خودکار پیام حاوی شماره کارت بعد از مدت‌زمانی قابل‌تنظیم توسط ادمین هم استفاده می‌شود
- 📣 **ابزارهای مستقل ارسال پست تبلیغاتی به کانال** (`channel_post_tool.py`, `channel_add_button_tool.py`) — ارسال پست (عکس + کپشن + دکمه‌ی دیپ‌لینک) به کانال از خط فرمان، یا افزودن دکمه‌ی دیپ‌لینک زیر یک پست از قبل منتشرشده در کانال بدون نیاز به آپلود دوباره‌ی عکس

### 🤝 نمایندگی، تخفیف و کیف پول
- 👥 **سیستم زیرمجموعه‌گیری (Referral) با سه مدل مستقل و قابل فعال/غیرفعال‌سازی جداگانه** — هر کاربر یک لینک دعوت اختصاصی دارد (`https://t.me/BOT?start=ref<user_id>`) و بر اساس مدل‌های فعال، پاداش به‌صورت خودکار به کیف پولش اضافه یا برایش کانفیگ ساخته می‌شود:
  - **① پورسانت درصدی از خرید** — با تایید **اولین خرید** هر زیرمجموعه، درصدی (قابل‌تنظیم) از مبلغ پرداختی او به کیف پول دعوت‌کننده اضافه می‌شود؛ با امکان تعیین سقف تعداد نفرات (مثلاً فقط ۵ نفر اول از زیرمجموعه‌هایی که خرید می‌کنند، پورسانت‌دار باشند — یا نامحدود)
  - **② کانفیگ رایگان با تعداد دعوت مشخص** — با رسیدن تعداد کل زیرمجموعه‌های دعوت‌شده (بدون نیاز به خرید آن‌ها) به یک آستانه‌ی مشخص (مثلاً ۱۰ نفر)، یک محصول از پیش‌تعیین‌شده توسط ادمین به‌صورت خودکار روی پنل ساخته و لینک آن برای دعوت‌کننده ارسال می‌شود؛ می‌توان محصولی جدا و غیرفعال (که در فروشگاه اصلی به مشتری نمایش داده نمی‌شود) مخصوص همین جایزه تعریف کرد
  - **③ شارژ ثابت کیف پول به‌ازای هر دعوت** — با ورود هر نفر از طریق لینک دعوت (بدون نیاز به خرید)، مبلغی ثابت (قابل‌تنظیم) بلافاصله به کیف پول دعوت‌کننده اضافه می‌شود؛ با امکان تعیین سقف تعداد دعوت‌هایی که این پاداش را دارند (مثلاً فقط ۱۰ نفر اول دعوت‌شده — یا نامحدود)
- 🏷️ کد تخفیف با درصد یا مبلغ ثابت، سقف تعداد استفاده و فعال/غیرفعال‌سازی
- 🎡 چرخ شانس با درصد احتمال برد، لیست جوایز، زمان انقضای کد جایزه و فاصله‌ی زمانی (Cooldown) قابل‌تنظیم بین دو چرخش هر کاربر

### 👑 پنل مدیریت (سه‌سطحی + یک نقش ویژه)
- 👑 **مالک (Owner)** — دسترسی کامل و بدون محدودیت؛ تنها نقشی که غیرقابل‌حذف و غیرقابل‌واگذاری است
- 🛡 **مدیر کامل (Admin)** — دسترسی به تمام بخش‌ها به‌جز مواردی که مخصوص مالک تعریف شده
- 🥈 **ادمین میانی (Mid)** — دسترسی عملیاتی روزمره (تایید سفارش/شارژ کیف پول، ارسال کانفیگ، مدیریت تیکت‌ها و...) بدون دسترسی به بخش‌های حساس مثل آمار فروش، چیدمان منو، تنظیمات کمپین/تخفیف، لاگ ادمین‌ها، نمایندگی‌ها، برندینگ و مدیریت محصولات/دسته‌بندی/بانک کانفیگ
- 🎧 **پشتیبان (Support)** — محدودترین نقش؛ فقط پاسخ‌گویی به کاربران و تیکت‌ها
- 📢 ارسال پیام همگانی (Broadcast)
- 📈 آمار فروش با فیلتر بازه‌ی زمانی
- 📝 **لاگ کامل فعالیت ادمین‌ها (Audit Log)** — ثبت هر اقدام حساس همراه با شرح و زمان
- 🗄️ **بکاپ‌گیری خودکار روزانه** از دیتابیس با ارسال فایل به تلگرام مالک و نگهداری چند نسخه‌ی آخر، به‌علاوه‌ی امکان **دریافت بکاپ فوری** و **بازیابی کامل دیتابیس** از روی فایل آپلودی (با اعتبارسنجی فایل sqlite و ذخیره‌ی خودکار یک نسخه‌ی امن پیش از بازیابی)
- 📅 پشتیبانی کامل از تاریخ شمسی (جلالی) با فیلتر انعطاف‌پذیر بازه‌ی زمانی، هم در بات و هم در Mini App

## 📲 Mini App

پوشه‌ی `miniapp/` شامل یک اپلیکیشن کامل تلگرام (Telegram Mini App) با دو بخش مجزا است: **فروشگاه کاربر** و **پنل مدیریت وب کامل**.

### 🛍️ بخش کاربر
- ⚡ بک‌اند FastAPI با احراز هویت امن (HMAC-SHA256 روی initData) — آیدی کاربر همیشه سمت سرور استخراج می‌شود، نه از ورودی کلاینت
- 🎨 طراحی هولوگرافیک/رتروویو (Retrowave) شیشه‌ای (Glassmorphism) با المان‌های انیمیشنی و فونت‌های Audiowide و Vazirmatn
- 🛒 فروشگاه، سبد خرید چندتایی، کیف پول، چرخ شانس، زیرمجموعه‌گیری و کانفیگ تست در قالب تب‌های اختصاصی
- 🔔 بنر هشدار نزدیک‌شدن انقضا/اتمام حجم در صفحه‌ی اصلی
- 📲 **افزودن خودکار اشتراک به اپ‌های VPN** — برای هر کانفیگ خریداری‌شده، انتخاب پلتفرم (iOS/اندروید) و سپس یکی از اپ‌های محبوب (Shadowrocket، Streisand، V2Box برای iOS؛ Hiddify Next، v2RayTun، V2Box، v2rayNG برای اندروید) با دو دکمه‌ی «⬇️ دانلود» (باز کردن صفحه‌ی اپ در استور) و «📲 افزودن» (وارد کردن مستقیم اشتراک به اپ نصب‌شده از طریق Deep Link اختصاصی هر اپ)
- 🎫 سیستم تیکت و چت پشتیبانی زنده داخل اپلیکیشن

### 🛠️ پنل مدیریت وب (داخل Mini App)
یک پنل مدیریت کامل و مستقل، موازی با پنل بات، شامل:
- 📊 داشبورد آماری و خروجی اکسل/CSV از سفارش‌ها
- 🗂️ مدیریت دسته‌بندی‌ها، محصولات و بانک کانفیگ (افزودن دستی یا برداشت تصادفی از انبار)
- 🏢 مدیریت کامل نمایندگان (افزودن، اعتبارسنجی توکن بات، فعال/غیرفعال‌سازی)
- 🏷️ مدیریت کدهای تخفیف، تنظیمات چرخ شانس، زیرمجموعه‌گیری، یادآوری تمدید و یادآوری اتمام حجم
- 👥 مدیریت کاربران — مشاهده‌ی جزئیات، مسدودسازی، ارسال پیام مستقیم، پیام همگانی به کاربران منقضی‌شده
- 💰 جست‌وجوی کیف پول کاربر و اصلاح دستی موجودی
- 🎨 شخصی‌سازی برندینگ، تم رنگی و تصویر هدر فروشگاه
- 🧩 مدیریت چیدمان منوی اصلی بات از همین پنل وب
- 🎫 مدیریت کامل تیکت‌ها و مکالمات پشتیبانی
- 📝 مشاهده‌ی لاگ‌های سیستم و لاگ فعالیت ادمین‌ها
- 🗄️ دریافت بکاپ فوری و بازیابی دیتابیس مستقیماً از پنل وب

برای نصب و اتصال Mini App به دامنه‌ی خودت (با SSL خودکار)، از گزینه‌ی ۱۰ در `manage.sh` استفاده کن.

## 🖥️ پنل مدیریت وب مستقل (`admin_panel`)

علاوه بر پنل مدیریتِ داخل بات و پنل مدیریتِ داخل Mini App، پروژه یک **پنل مدیریت وب کاملاً مستقل و جدا از تلگرام** هم دارد (پوشه‌ی `admin_panel/`) که می‌تواند حتی بدون باز بودن بات هم روی دامنه‌ی اختصاصی خودش بالا بماند:

- 🔐 لاگین با **یوزرنیم/پسورد** (نه از طریق تلگرام) و سیستم نشست (session) امضاشده‌ی مستقل
- 👥 **مدیریت کاربران پنل وب** با نقش و سطح دسترسی جدا از نقش‌های ادمین بات (owner و نقش‌های قابل‌تعریف دیگر)
- 📊 داشبورد کامل آمار فروش، سفارش‌ها، شارژ کیف پول و وضعیت سیستم (`/api/system/stats`, `/api/system/jobs`)
- 🌍 **نقشه‌ی جهانی سرورها** — اسکن خودکار لینک ساب مادر، استخراج و geolocate کردن IP سرورهای پشت هر کانفیگ (vmess/vless/trojan/ss/hysteria2/tuic) و نمایش آن‌ها روی نقشه‌ی جهان در داشبورد، همراه با تست آنلاین/آفلاین بودن هرکدام
- 💱 نمایش و بروزرسانی دستی/خودکار نرخ ارز مورد استفاده برای قیمت‌گذاری
- ✅ تایید/رد سفارش‌ها، شارژ کیف پول و رسیدهای پرداخت مستقیماً از پنل وب (بدون نیاز به تلگرام)
- 🏢 مدیریت کامل نمایندگان به‌همراه **آنالیز کوهورت (Cohort Analytics)** نمایندگان
- 🎫 مدیریت تیکت‌ها و مکالمات پشتیبانی
- 📢 ارسال پیام همگانی (Broadcast)
- 🗄️ دریافت بکاپ فوری و بازیابی دیتابیس
- 🔔 **اعلان Push در مرورگر (Web Push / VAPID)** — اطلاع‌رسانی سفارش/تیکت/شارژ جدید به ادمین حتی وقتی تب پنل بسته باشد (نیاز به ساخت کلید VAPID دارد)
- 📝 لاگ کامل فعالیت ادمین‌های پنل وب

### راه‌اندازی

**خودکار (پیشنهادی):** گزینه‌ی ۱۳ در `manage.sh` — دامنه، SSL و سرویس سیستم‌دی را خودش می‌سازد.

**دستی:**
```bash
# ساخت اولین حساب owner پنل وب (یوزرنیم/پسورد)
python -m admin_panel.create_admin <username> <password>

# اجرای پنل (پشت یک ریورس‌پروکسی Nginx با SSL قرار بده)
uvicorn admin_panel.server:app --host 127.0.0.1 --port 8002
```

برای فعال‌سازی اعلان‌های Push مرورگر، یک‌بار کلید VAPID بساز (یا از گزینه‌ی ۱۶ منوی `manage.sh` استفاده کن) و خروجی را داخل `.env` قرار بده:
```bash
python -m admin_panel.generate_vapid_keys
```

## 🔌 پنل‌های VPN پشتیبانی‌شده

اتصال و **تحویل خودکار (Auto-Provision)** کاربر روی پنل، از طریق یک لایه‌ی provider مستقل (`panel_providers/`) پیاده‌سازی شده:

| نوع پنل | وضعیت | نکته |
|---|---|---|
| PasarGuard | ✅ پشتیبانی کامل | احراز هویت با Bearer token؛ گروه/اینباند کاربر جدید از روی یک کاربر نمونه‌ی از قبل موجود روی پنل کپی می‌شود |
| Marzban | ✅ پشتیبانی کامل | همان روش احراز هویت PasarGuard (لاگین با یوزر/پس روی `/api/admin/token`)؛ تفاوت فقط در نام‌گذاری فیلدهای proxies/inbounds |
| Marzneshin | ✅ پشتیبانی کامل | دسترسی کاربر از طریق «سرویس» (Service) به‌جای proxies/inbounds خام؛ endpoint احراز هویت جمع بسته (`/api/admins/token`) |
| Hiddify | ✅ پشتیبانی کامل | احراز هویت با API Key ثابت (نه لاگین یوزر/پس)؛ هویت کاربر روی پنل یک UUID است |
| 3X-UI | ✅ پشتیبانی کامل | احراز هویت با Bearer API Token (ساخته‌شده از داخل پنل، سازگار با نسخه‌های جدید که لاگین برنامه‌نویسی را می‌بندند)؛ هر کاربر به یک inbound مشخص روی سرور اضافه می‌شود |
| پنل‌های دیگر | ➕ قابل افزودن | با پیاده‌سازی یک provider جدید طبق اینترفیس `panel_providers/base.py` و رجیستر آن در `panel_providers/__init__.py` |

> 💡 دریافت **اطلاعات زنده‌ی اشتراک** (حجم/انقضا از روی لینک ساب کاربر — `sub_info.py`) کاملاً مستقل از این لایه است و با هر نوع پنلی کار می‌کند، چون مستقیم خروجی ساب را می‌خواند نه API پنل را.

```bash

```

این اسکریپت به‌صورت خودکار:

1. ✅ پیش‌نیازهای سیستمی (`git`, `python3`, `pip`, `venv`) را نصب می‌کند
2. ✅ پروژه را از گیت‌هاب کلون می‌کند (یا در صورت وجود، آپدیت می‌کند)
3. ✅ محیط مجازی پایتون را می‌سازد و پکیج‌ها را نصب می‌کند
4. ✅ توکن بات و آیدی عددی ادمین را از تو می‌پرسد و فایل `.env` را می‌سازد
5. ✅ یک سرویس `systemd` می‌سازد تا بات همیشه در حال اجرا بماند و بعد از ری‌استارت سرور هم خودکار بالا بیاید

بعد از پایان نصب می‌توانی با دستورهای زیر وضعیت بات را مدیریت کنی:

```bash
sudo systemctl restart v2raybot    # ری‌استارت
sudo systemctl stop v2raybot       # توقف
```

برای آپدیت بات در آینده، کافیست همان دستور نصب یک‌خطی بالا را دوباره اجرا کنی (idempotent است و اطلاعات `.env` را دست‌نخورده نگه می‌دارد)، یا از [پنل مدیریت متنی (`manage.sh`)](#-مدیریت-بات-managesh) استفاده کنی که تمام این کارها (نصب، آپدیت، ری‌استارت، مشاهده‌ی لاگ و ...) را با یک منوی ساده انجام می‌دهد:

```bash

```

## 🛠 نصب دستی

اگر ترجیح می‌دهی مراحل را دستی و قدم‌به‌قدم انجام دهی:

**۱. کلون کردن پروژه**
```bash
git clone https://github.com/mehdirafatpanah/Shopvpn.git
cd Shopvpn
```

**۲. ساخت محیط مجازی و نصب پکیج‌ها**
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

**۳. تنظیم فایل `.env`**
```bash
cp .env.example .env
nano .env
```

مقادیر زیر را در فایل `.env` قرار بده:
```env
BOT_TOKEN=توکن_واقعی_بات
OWNER_ID=آیدی_عددی_تو
```

> 🔒 فایل `.env` هرگز نباید وارد گیت‌هاب شود (در `.gitignore` قرار دارد). فقط `.env.example` بدون مقدار واقعی در ریپازیتوری نگه‌داری می‌شود.

## ⚙️ متغیرهای محیطی (.env)

`BOT_TOKEN` و `OWNER_ID` تنها متغیرهای **اجباری** هستند؛ بدون آن‌ها بات اصلاً بالا نمی‌آید. بقیه‌ی متغیرها اختیاری‌اند و فقط قابلیت مربوطه را فعال می‌کنند — اگر خالی بمانند، همان بخش به‌آرامی غیرفعال می‌ماند و بقیه‌ی پروژه بدون مشکل کار می‌کند.

| متغیر | اجباری؟ | توضیح |
|---|:---:|---|
| `BOT_TOKEN` | ✅ | توکن بات اصلی، از [@BotFather](https://t.me/BotFather) |
| `OWNER_ID` | ✅ | آیدی عددی تلگرام مالک پروژه |
| `MINIAPP_URL` | ➖ | آدرس HTTPS مینی‌اپ؛ خالی یعنی دکمه‌ی مینی‌اپ در بات نمایش داده نمی‌شود |
| `API_BASE_URL` | ➖ | آدرس پایه‌ی API مینی‌اپ (برای کال‌بک پرداخت کریپتو Plisio)؛ اگر خالی باشد خودکار از روی `MINIAPP_URL` استخراج می‌شود |
| `PLISIO_API_KEY` | ➖ | کلید API درگاه پرداخت کریپتو [Plisio](https://plisio.net) به‌عنوان فال‌بک سراسری (هر بات می‌تواند کلید اختصاصی خودش را هم از داخل پنل تنظیم کند) |
| `ABANGATEWAY_API_KEY` | ➖ | کلید API درگاه پرداخت کارت‌به‌کارت خودکار [آبان گیت وی](https://abangateway.ir) به‌عنوان فال‌بک سراسری (هر بات می‌تواند کلید اختصاصی خودش را از داخل پنل، دکمه‌ی «تنظیم درگاه آبان گیت وی»، تنظیم کند) |
| `ADMIN_PANEL_SECRET` | ➖ | کلید امضای نشست (session) پنل مدیریت وب مستقل؛ اگر ست نشود مقدار تصادفی ساخته می‌شود (با هر ری‌استارت، نشست‌های قبلی باطل می‌شوند) |
| `ADMIN_PANEL_URL` | ➖ | آدرس دامنه‌ی پنل مدیریت وب مستقل (`admin_panel/`) |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` | ➖ | کلیدهای اعلان Push مرورگر برای پنل وب مستقل؛ با `python -m admin_panel.generate_vapid_keys` ساخته می‌شوند |
| `VAPID_CLAIM_EMAIL` | ➖ | ایمیل تماس همراه کلید VAPID (پیش‌فرض: `admin@example.com`) |

**۴. اجرا**
```bash
python main.py
```

اگر همه‌چیز درست باشد، بات بلافاصله روشن می‌شود و آماده‌ی دریافت پیام است. دیتابیس به‌صورت خودکار در همان پوشه ساخته می‌شود (`bot_database.db`)؛ نیازی به نصب هیچ دیتابیس جداگانه‌ای نیست.

**۵. اجرای دائمی (بدون بستن ترمینال)**

```bash
# روش ساده با screen
screen -S v2raybot
python main.py
# سپس Ctrl+A و D برای خروج بدون بستن بات

# یا با nohup
nohup python main.py > bot.log 2>&1 &
```

بهترین روش برای پروداکشن، ساخت یک سرویس `systemd` است (که [نصب خودکار](#-نصب-خودکار-یک‌خطی-پیشنهادی) این کار را خودش انجام می‌دهد).

> 💡 بعد از نصب دستی هم می‌توانی مدیریت روزمره‌ی بات (وضعیت، لاگ، ری‌استارت، آمار فروش و Mini App) را با [پنل مدیریت متنی (`manage.sh`)](#-مدیریت-بات-managesh) انجام دهی.
