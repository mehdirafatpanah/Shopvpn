<a id="overview"></a>

## 📖 Обзор

**ShopVPN** — это Telegram-бот промышленного уровня для продажи и управления конфигурациями V2Ray/VPN. Он объединяет автоматическую выдачу конфигураций, множество способов оплаты, управление реселлерами, ИИ-поддержку, мини-приложение Telegram, отдельную веб-панель администратора и инфраструктуру для управления через Android.

Проект рассчитан на реальную эксплуатацию: кошельки, реферальная программа, скидки, тикеты поддержки, мониторинг, резервное копирование, отчёты, настраиваемые товары и поддержка мультибот-реселлеров.

### 📢 Официальные ссылки

- 📢 **Проект:** [@celenorbot](https://t.me/celenorbot)
- 👤 **Автор:** [@celenor](https://t.me/celenor)

### ⚡ Краткое описание

- 🔑 Автоматическая выдача конфигураций на поддерживаемых VPN-панелях
- 💳 Несколько автоматических способов оплаты
- 🧠 ИИ-помощник поддержки
- 🔄 Гибкое продление услуг
- 🏢 Независимый и связанный режимы реселлера
- 🖥️ Админка в Telegram + веб-админка + Android-приложение управления
- 📲 Витрина в виде мини-приложения Telegram
- 🌍 Карта серверов и мониторинг состояния панелей
- 🌐 Поддержка Polling и Webhook
- 🚀 Антиспам, отчёты, резервные копии, кешбэк, монеты, лотерея, подарки и Integration API

<a id="auto-install"></a>

## 🚀 Автоматическая установка в одну строку

**Рекомендуется:** на чистом сервере Ubuntu/Debian выполните:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/mehdirafatpanah/Shopvpn/main/manage.sh)
```

<details>
<summary><strong>Что делает установщик?</strong></summary>

1. Устанавливает системные зависимости
2. Клонирует или обновляет проект
3. Создаёт виртуальное окружение Python
4. Устанавливает необходимые пакеты
5. Создаёт/настраивает `.env`
6. Создаёт службу systemd
7. Запускает бота и поддерживает его работу после перезагрузки сервера

### Основные команды управления службой

```bash
sudo systemctl status v2raybot
sudo journalctl -u v2raybot -f
sudo systemctl restart v2raybot
sudo systemctl stop v2raybot
```

Тот же установщик в одну строку можно запускать повторно для будущих обновлений.

</details>

<a id="manual-install"></a>

## 🛠️ Ручная установка

<details>
<summary><strong>Нажмите, чтобы развернуть</strong></summary>

### 1. Клонирование

```bash
git clone https://github.com/mehdirafatpanah/Shopvpn.git
cd Shopvpn
```

### 2. Создание виртуального окружения

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Настройка `.env`

```bash
cp .env.example .env
nano .env
```

Как минимум:

```env
BOT_TOKEN=your_bot_token
OWNER_ID=your_numeric_telegram_id
```

### 4. Запуск

```bash
python main.py
```

Для промышленной эксплуатации используйте автоматический установщик/systemd или другой менеджер процессов.

</details>
